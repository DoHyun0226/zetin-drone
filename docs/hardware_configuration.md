# 하드웨어 구성과 확인할 항목

**2026-09-07 자료 대조.** 아래 표는 코드로 확인한 연결과 이전 실물 기록을
구분한다. 지금 연결된 기체를 직접 점검한 결과가 아니다.

| 계통 | 코드가 지원하는 것 | 실물 기록·남은 확인 |
|---|---|---|
| 연산·FC | ESP32-S3, 통신/센서 수신과 제어 태스크 분리 | 노션 8/24 기록은 N16R8·실물 PCB v1.4.3·차기 v1.5.2. 실제 장착 개정 확인 필요 |
| 자세 | ICM42670 듀얼 IMU, SPI | IMU2 부호·기체축은 [개요](project_overview.md#센서축과-기체축). 장착 방향을 실물 대조 |
| 방위 | BMM350, I2C, hard/soft-iron·전류 간섭 보정 | [재보정 절차](bmm350_yaw_bench_test.md). 장착·배선 변화 후 재검증 |
| 거리·광류 | Matek 3901-L0X MSPv2 UART 수신 | 장착 기록은 있지만 최근 시험의 신선한 값 미확보. 제어에는 사용하지 않음 |
| 구동 | 4채널 PWM ESC | 이전 기록은 30A ESC·1750KV급 모터 각 4개. 실제 SKU·프롭 규격·회전방향 확인 필요 |
| 전원 | 현행 텔레메트리에 배터리 전압 없음 | 이전 기록은 4S 3000mAh. 현재 배터리·상태·전원 배선 확인 필요 |
| 기구 | 코드로 모델·재질·질량을 확정할 수 없음 | 이전 기록은 분할 출력 암·상하판. CAD 원본·리비전·질량·무게중심 확인 필요 |

핀 번호·센서축·모터 순서는 [프로젝트 개요](project_overview.md)와
[펌웨어 가이드](../firmware/README.md)가 정본이다. 진단 스케치마다 핀이 다를 수
있으므로 이전 연결을 그대로 적용하지 않는다.

노션의 [하드웨어 구성·BOM](https://app.notion.com/p/3c62d27b08d381d3a616e69d58540508)은
당시 실물 정보와 예비 비용·제작시간을 갖는다. 산정 원본은 별도
`zetin-drone-presentations` 저장소에 있다. 예비 산정은 구매 완료 목록이나
완성 기체 총원가가 아니며, 코드에서 확인되지 않는 부품 정보를 확정하지 않는다.

다음 실물 점검에서는 보드 앞뒤 사진·개정, 센서 전원/신호 배선, ESC·모터·프롭
라벨, 배터리, 기구 파일 위치와 체결 상태를 확인하고 위 표를 갱신한다.
