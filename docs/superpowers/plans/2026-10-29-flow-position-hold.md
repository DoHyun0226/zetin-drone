# 광류 위치 유지 (flow hold) 설계·구현 계획

> **구현자 규칙:** RED→GREEN TDD. 각 테스트는 먼저 실패를 확인하고 구현한다.
> 보드 업로드·모터 구동·push 는 이 계획 범위 밖이며 별도 승인을 받는다.

**목표:** Matek 3901-L0X 의 광류·거리로 (1) 광류 보정, (2) 수평 속도·높이 추정,
(3) 제자리 호버링(수평 위치 유지 + 선택적 고도 유지)을 한다.

**관리 방식 (사용자 결정, 2026-10-29):** 기존 주력 `dual_imu_cascade_pwm` 은
건드리지 않는다. 그 스케치를 복사한 새 스케치
`firmware/flight/dual_imu_cascade_flow_hold/` 에서만 기능을 추가한다.
복사 기준은 `dual_imu_cascade_pwm` 의 작업 트리(HEAD `9608f69` + 3901 RX
GPIO17 변경)다. 공유 헤더 6개는 바이트 동일을 시험으로 강제한다.

## 2. 물리와 부호 (손으로 유도, 테스트로 고정)

아래를 보는 센서가 광축 거리 d 에서 기체 속도 v(기체 x 전방, y 우측, FRD)와
기체 각속도 (p, q) [rad/s] 를 가질 때, 광축 중심 시선의 기체 기준 각속도는

```
ω_meas = ( v_y/d − p ,  −v_x/d − q )     [rad/s, 기체 x·y 축 성분]
```

이다(지면점 상대위치 r = d·n, ṙ = −v, ω = r×ṙ/|r|² 에서 기체 회전 −ω_b 를 더함).
v 는 광축에 수직인 기체 좌표 성분이고, d 는 거리계가 재는 **광축 방향 거리
(slant)** 다. 거리계와 광류가 같은 방향을 본다고 가정한다.

1. **순수 회전**(v=0)이면 ω_meas = −(p, q). 보정은 이 관계만 쓴다. 광류 한
   구간의 자이로 적분 g = ∫(p,q)dt [**rad**] 와 광류 카운트 f 를 모아
   `f ≈ M · g` 인 2×2 행렬 M [counts/rad] 를 최소제곱으로 구한다. M 에 축
   대응·부호·스케일이 모두 들어 있다(INAV 의 counts/deg 10.5 ≈ 601.6 counts/rad).
2. **등가 회전:** u = M⁻¹ f [rad] 는 "같은 광류를 만들 자이로 적분"이다.
   순수 회전이면 u = g, 그러므로 **u_t = u − g 가 병진 성분만**이다.
3. 병진만 있을 때 u_t/dt = −ω_meas = (−v_y/d, v_x/d) [rad/s].
4. 보정 공간 속도 **c = u_t·d/dt [m/s]** 로 정의한다: c_roll = −v_y, c_pitch = v_x.
5. **보정 방향 = c 의 방향:** 기수를 들면(+pitch) 추력이 뒤로 기울어 전방
   이동(c_pitch>0)을 줄이고, 좌로 기울이면(−roll) 우측 이동(c_roll<0)을 줄인다.
   즉 "이동을 멈추는 자세 변화"는 c 와 **같은 부호**다. 펌웨어 angle = ∫gyro 이므로
   같은 축·같은 부호로 목표각에 더한다.
6. 위치: P = ∫c dt (보정 공간 변위, m). 앞으로 D 만큼 밀리면 P_pitch = +D.
   되돌아가는 목표 속도는 c_t = K_pos·(P_ref − P) (전방으로 밀렸으면 c_t<0 = 후진).
   **제어 오차 e = c − c_t**, Δangle = K_v·e + I. (예: 전방 0.3 m/s, 위치 오차
   0 → e = +0.3 → Δpitch = +1.2° 기수 들림 = 제동.)

- 고도용 수직 높이: h = d·cos(roll)·cos(pitch). 광류 환산에는 d 를 그대로 쓴다.
- v1 의 기울기 허용치는 축별 20°(두 축 동시면 총 약 28°). 수직속도 0.3 m/s 가 기체
  좌표 수평 성분으로 새는 양은 총 기울기 28° 에서 0.3·sin28° ≈ 0.14 m/s 이며,
  이 오차 예산을 받아들인다.
- **가속도계 기울기 보정(구현 중 추가, §4.7):** 기울어 가속하는 쿼드의 가속도계는
  추력 방향만 본다. 상보필터가 그것을 수평으로 읽어 추정이 실제 기울기보다 작아지고,
  위치 루프에 느린 적분기가 하나 더 생겨 발산한다.
- yaw: v1 은 위치를 **기체 좌표**로 적분하고 yaw 회전을 적용하지 않는다(§4.3).

> **정정 (2026-10-30 실기 벤치):** 위 유도는 FRD(+pitch = 기수 들림)로 썼다. 이 펌웨어의
> 실기체 규약은 +pitch = 기수 숙임(스틱 앞 = 양의 pitch 목표 = 전진)이라 실기체에서는
> **c_pitch = −v_전방**, c_roll = −v_우측 이다. 5·6 의 제어 규칙은 두 부호가 함께 뒤집혀
> 그대로 제동한다(전방 이동 → c_pitch < 0 → pitch 감소 = 기수 들림). 손 시험 실측과
> Codex 검토로 확인했다(§8 "실기 벤치").

## 3. 범위

**한다**
- 새 스케치 `dual_imu_cascade_flow_hold` (기존 스케치 복사 + 아래 추가).
- 순수 헤더 3개(호스트 테스트 대상, 새 스케치 폴더 안):
  - `flow_calibration.h` — 지연 후보별 보정 누적·2×2 최소제곱·판정.
  - `flow_odometry.h` — 자이로 이력, 높이·수직속도, 광류 → 보정 공간 속도.
  - `flow_hold.h` — 위치 유지·고도 유지 상태기계와 제어기.
- 명령: `flowcal 1|0`, `poshold 1|0`, `althold 1|0`, `hg <name> <value>`.
- 텔레메트리 인덱스 75 부터 append (기존 0~74 불변).
- 지상국: `telemetry_schema.py` 새 필드(구형 패킷은 None), `control_dualsense.py`
  stdin 명령 전달·상태 표시·`FLOWCAL,` 결과 패킷 출력.
- 테스트: 헤더 단위 테스트, 새 스케치 SIL(수평 동역학 + 가짜 MSP 센서),
  공유 헤더 동일성 검사(완료), Arduino 컴파일.

**하지 않는다**
- 기존 `dual_imu_cascade_pwm` 의 동작 변경.
- 자동착륙·failsafe 경로 변경. 보류 모드는 failsafe 중 꺼진다.
- 자동 이륙·착륙, 거리계 기반 착지 판정.
- 가속도 융합(INS), yaw 회전을 반영한 월드 좌표 위치 유지(§7 후속).
- 보드 업로드·비행.

## 4. 설계

### 4.1 데이터 경로와 시간 정렬

- Core 0 `pollMspSensor` 가 프레임 완성 시점의 `micros()` 를 붙여 광류
  `{seq, fx, fy, quality, t_us, timing_ok}` 와 거리 `{seq, range_mm, t_us,
  timing_ok}` 를 `flowSampleMux` 아래 스냅샷으로 게시한다. seq 는 로컬 카운터다.
- `timing_ok`: 직전 `pollMspSensor` 호출과의 간격이 `FLOW_POLL_GAP_MAX_US`
  (15 ms) 이하이고 **직전 폴링이 FIFO 에 바이트를 남기지 않았을 때만** 참. 정체 직후 첫
  폴링은 바이트 예산(64 B) 때문에 backlog 를 다 못 꺼내므로 다음 폴링도 걸러야 한다(SIL 에서
  발견). 광류·거리 둘 다 적용한다 — 거리에 빠뜨리면 오래된 높이가 현재 시각으로 차분돼
  가짜 수직속도가 된다(코드 리뷰 P1-3).
- **유실 검출:** MSP 에 송신 seq 가 없지만 센서가 100 ms 주기로 보내므로 유실은
  도착 간격으로 드러난다. 80~130 ms 는 정상. 160~260 ms(프레임 하나 유실)는 이
  프레임이 마지막 한 주기만 덮는다고 보고 그 절반 구간으로 속도를, 간격 전체(span)로
  위치를 적분한다. 그 밖은 버린다. 부팅·재개·타이밍 리셋 뒤 첫 프레임은 버린다.
  (초안의 "CRC 오류 카운터가 늘면 다음 구간 폐기" 규칙은 구현 중 삭제했다 — 거리
  프레임의 CRC 오류까지 광류 구간을 버리는 과잉 거부였고, 광류 유실은 간격으로 이미 잡힌다.)
- 소비 시점: 자이로 이력이 그 구간 끝(도착 − 지연)까지 쌓인 뒤에 쓴다. 이력 적분은
  10 ms 초과 치환 전의 실제 dt 를 쓰고, 10 ms 넘는 공백이면 이력과 광류 구간을 새로
  시작한다. 타이밍을 못 믿는 프레임은 다음 구간의 시작점으로도 쓰지 않는다.
- **자이로 이력:** Core 1 이 1 kHz 로 roll/pitch 누적각 [rad] 을 타임스탬프와 함께
  512 칸 링에 쓴다(512 ms). 광류 구간 [t − dt − τ, t − τ] 의 g 는 링에서 두 시점의
  누적각 차로 구한다(선형 보간). τ = `flow_gyro_delay_us`, 기본 0, 보정이 추정.
- 회전율 게이트: 구간 평균 |ω| > `FLOW_MAX_ROT_RATE` (2.0 rad/s ≈ 115 °/s) 면
  위치 유지 갱신에 쓰지 않는다(회전 상쇄 오차가 회전율 × 시간오차에 비례).
  보정 누적에는 쓴다(보정은 회전이 필요). 7.4 rad/s 초과 광류는 모두 버린다.

### 4.2 보정 (`flowcal`)

- 시동 해제 상태에서만 시작. 시작 중 `start` 는 거부. 손으로 들고 바닥
  40~70 cm 위에서 제자리로 roll·pitch 를 **따로따로** 흔든다(각 10 s 이상).
  회전 중심은 센서에 가깝게. **±10~15°, 0.5~1 Hz** 권장 — 최소 고유값 문턱은 축마다
  같은 시간을 줄 때 ±7.3°@0.5 Hz, ±3.7°@1 Hz 이상을 요구한다(재검토 ②-P2-6). 그보다
  작게 흔들면 정상 데이터도 LOW_EXCITATION/COLLINEAR 로 거부된다.
- 지연 후보 τ ∈ {0, 10, …, 100 ms} 11개에 대해 각각 Σ g gᵀ, Σ f gᵀ, Σ f fᵀ 를
  누적(유효 샘플: quality ≥ `FLOW_MIN_QUALITY`, timing_ok, dt 유효, 거리 0.3~1.5 m).
  종료 시 후보마다 M = (Σ f gᵀ)(Σ g gᵀ)⁻¹, 잔차비 = 1 − R² 를 계산하고 잔차비가
  가장 작은 τ 를 고른다.
- 판정(모두 만족해야 `ok`):
  - 유효 샘플 ≥ 150 (약 15 s)
  - 입력 공분산 C = Σ g gᵀ / N 의 **최소 고유값 ≥ (0.02 rad)²** 이고 **조건수 ≤ 8**,
    축 상관 |ρ| ≤ 0.6 — 두 축을 독립적으로 흔들었는지(검토 ②-3)
  - 선택된 τ 의 잔차비 ≤ 0.25
  - M 이 부호 붙은 치환에 가깝다: 각 행의 작은 원소/큰 원소 ≤ 0.25, 두 행의 큰
    원소가 서로 다른 열
  - 큰 원소 크기 170~1700 counts/rad (= 3~30 counts/deg)
- 결과: `ok` 면 런타임 보정값(M, τ)으로 적용하고 Serial 과 UDP `FLOWCAL,...`
  패킷으로 결과와 붙여 넣을 상수 줄을 출력한다. 실패면 이유 코드.
- 컴파일 상수 `FLOW_CAL_M`/`FLOW_CAL_DELAY_US`/`FLOW_CAL_VALID` 기본은 미보정.
  런타임·컴파일 어느 쪽도 유효하지 않으면 `poshold 1` 을 거부한다.
- 한계(문서화): 손 보정의 회전축 오프셋 r 은 r/d 만큼 체계 오차를 만들고 반복해도
  드러나지 않는다. 비행 중에는 CG 기준으로 돌아 센서–CG 거리 r 만큼 r/d 오차가
  추가된다(d=0.5 m, r=3 cm 면 6%).

### 4.3 위치 유지 (`poshold`)

상태: `OFF` / `ACTIVE` / `COAST`(센서 일시 무효, ≤ 350 ms) / `SUSPENDED` /
`OVERRIDE`(조종 입력·yaw 회전).

- 요청은 지상국 명령, 판정과 적용은 Core 1 의 **매 tick**. 후보 출력과 적용 출력을
  분리한다. 시동 해제 중에도 후보는 계산해 텔레메트리로 보이고(**dry run**), 적용
  출력은 항상 0 이다.
- 유효 조건: 보정 유효, 새 광류 구간 유효(§4.1), quality ≥ `FLOW_MIN_QUALITY`(50),
  거리 유효 0.10~1.80 m 이고 h ≥ 0.15 m, |roll|,|pitch| ≤ 20°, 최근 광류 ≤ 300 ms.
- 무효 처리: 무효가 시작되면 `COAST` — 마지막 출력 유지. 350 ms 넘으면(프레임
  하나 유실은 유효 측정 간격 300 ms 라 COAST 로 넘긴다) `SUSPENDED` — 적분항을
  **포함한 전체 보정**을 τ 0.1 s 로 지수 감쇠(계단 리셋 금지, 검토 ③-1; 적분만 남기면
  외란이 사라진 뒤 조종 방향을 뒤집거나 센서 없이 계속 밀고 간다, 재검토 ②-P1).
  다시 유효해지면 현재 위치를 새 기준으로, 속도 LPF 를
  첫 측정값으로 초기화하고 `ACTIVE`.
- `OVERRIDE`: |조종 roll/pitch 명령| > 2° (RC 파서가 따로 저장한 순수 조종값),
  또는 |yaw 각속도 명령| > `YAW_RATE_DEADZONE`, 또는 |bodyGz| > 10 °/s, 또는 기준
  이후 |Δyaw| > 15°. 전체 보정 감쇠, 위치 기준을 현재 위치로 계속 갱신, 50 ms 유지 후 해제.
  yaw 조건은 부호와 무관한 크기 비교라 미검증 yaw 부호에 의존하지 않는다.
- 제어(보정 공간, 광류 구간마다 갱신, 사이는 유지):
  - c_f = 1차 LPF(c, τ 0.2 s). P += c·dt.
  - 리시: |P_ref − P| ≤ 1.0 m 가 되도록 P_ref 를 끌고 온다(검토 ③-8).
  - c_t = clamp(K_pos·(P_ref − P), ±0.3 m/s)
  - e = c_f − c_t
  - I += K_vi·e·dt (ACTIVE 이고 적용 출력이 포화되지 않았을 때만, clamp ±5°)
  - Δangle = clamp(K_v·e + I, ±8°)
  - 기본값(구현 중 SIL 격자 탐색으로 변경) K_pos 0.5 /s, K_v 6 deg/(m/s),
    K_vi 1.0 deg/(m/s·s), 속도 LPF τ 0.1 s. 1° 기울기 ≈ 0.171 m/s² → 속도 루프
    시정수 ≈ 1.0 s, 위치 루프 2 s. 탐색: K_v 3~8 × K_vi 0.3~2 × K_pos 0.3~0.8 × τ 0.1/0.2,
    조건 3개(저항 0.05·0.3 N/(m/s), 1.5 m·30 ms 지연)의 최악값 기준. 선택값의 늦은 구간
    속도 RMS ≤ 0.027 m/s, 최종 위치 오차 ≤ 0.08 m, 최대 기울기 ≤ 3.1°. 실기 재튜닝 대상.
- 후보 출력 변화율은 10 °/s 로 제한한다(재진입 계단 방지, 코드 리뷰 P2-5). 고도 유지는 300 us/s.
- 적용: outer loop 직전 목표 = targetAngleX/Y + Δ, 합계 ±30° clamp. 적용 보정이 0 이 되는
  tick 에는 outer loop 를 그 자리에서 다시 계산한다(250 Hz 분주로 이전 목표 각속도가 최대
  3 ms 남는 문제, 코드 리뷰 P2-4).
  RC 파서의 `targetAngleX/Y` 는 그대로 두고, 파서가 순수 조종값
  `pilotRollCmd/pilotPitchCmd` 를 함께 기록한다.

### 4.4 고도 유지 (`althold`)

상태: `OFF` / `ACTIVE` / `ADJUST`(조종자가 스로틀 조정 중) / `SUSPENDED`.

- `poshold` 와 독립. 켜는 순간의 높이와 스로틀을 기준으로 잡는다.
- h 는 거리 프레임마다 갱신. vz 는 차분 + LPF(τ 0.15 s). 무효→유효 첫 프레임은
  vz = 0 으로 초기화하고 차분하지 않는다.
- Δ = clamp(K_h·(h_ref − h) − K_vz·vz + I_h, ±60 us), I_h clamp ±40 us.
  기본 K_h 60 us/m, K_vz 60 us/(m/s), K_hi 15 us/(m·s).
  근거(SIL 기체): 1 us ≈ 0.0289 m/s² → ω_n ≈ 1.32 rad/s, ζ ≈ 0.66. 실기 추력 계수는
  미측정이라 보수적이다. ±60 us 는 큰 기울기에서 고도 유지를 보장하지 않는다
  (25° 기울기 호버에는 약 +74 us 필요) — 그래서 기울기 허용치도 20° 로 묶는다.
- 조종 스로틀: `base_throttle` 이 바뀌면 기준 스로틀을 현재 값으로 갱신하고
  `ADJUST` 로 간다. `ADJUST` 동안 Δ = I_h(동결), h_ref 는 h 를 따라간다. 마지막
  변경 후 500 ms 동안 바뀌지 않으면 h_ref = h 로 `ACTIVE` 복귀(검토 ②-5, ③-1).
- 거리 무효 300 ms → `SUSPENDED`: 비례·미분항은 τ 0.1 s, I_h 는 τ 1 s 로 감쇠
  (배터리 처짐 보상이 한순간에 빠져 떨어지지 않게).
- ADJUST 진입 순간 출력은 직전 값에서 이어진다(±1 us 버튼 한 번이 수십 us 계단이 되지 않게).
- **지면 컷 경계:** base_throttle ≤ `FS_GROUND_CUT_MAX_US`(1150) 이면 적용 보정은 0 이다.
  RC 끊김 판정이 그 base 를 지상으로 보므로, +Δ 로 떠 있으면 링크 상실 때 공중 컷이 된다
  (재검토 ②-P1, 코드 리뷰 P1-2). 1150~1210 구간에서는 `inhibit` 로 보정을 τ 0.1 s 로 미리
  감쇠시켜 경계에서의 계단을 줄인다(상태 리셋은 하지 않는다 — 리셋하면 그 순간 계단).
- 적용: mixer 에 요청하는 collective = base_throttle + Δ. 자세 여유가 줄지 않도록
  기존 min/max clamp 결과에 Δ 를 더하고 1050/1900 으로 다시 clamp 한다. hover 추정기의
  샘플·자격 조건과 자기계 전류 보정은 직전 tick 의 base+Δ(**요청값**)를 쓴다 — 원본이
  요청값 base_throttle 을 썼고 failsafe 도 hover_est 를 요청값으로 다시 쓰므로 의미를
  맞춘다. allocator 가 자세 차동 때문에 전달 collective 를 옮길 수 있다는 점(재검토
  ②-P2-3)은 원본과 같은 성질로 받아들인다. RC 지상 컷 판정은 기존 base 그대로다.

### 4.5 안전

- `safety_lock` 또는 `fs_phase != FS_NONE` 이면 그 tick 부터 적용 출력 0 (적용값은
  failsafe 판정이 끝난 뒤 그 tick 의 최종 상태로 확정한다). 시동 해제 중 후보 계산
  상태는 유지한다(dry run). 시동·해제·failsafe **경계에서** 내부 상태를 리셋한다.
  failsafe 경로·RC 감시·컷 조건은 그대로다.
- 시동(`start`) 시 두 모드의 요청은 유지하되 내부 상태를 리셋한다. `stop` 은 요청을
  모두 끈다. `resume` 은 요청을 끈 채로 둔다(조종자가 다시 켠다).
- 보정·gain 변경(`flowcal`, `hg`)은 시동 해제에서만. `flowcal` 진행 중 `start` 거부.
- 출력 상한: 자세 ±8°, collective ±60 us (`CTRL_MARGIN` 150 보다 작음).
- `udp_task` 스택을 6144 B 로 늘린다(필드 91개 printf). 새 스케치에만.

### 4.7 가속도계 기울기 보정 (구현 중 추가)

SIL 에서 처음 이득(K_v 4)으로 위치 유지가 주기 6 s 로 감쇠 없이 흔들렸다. 로그로 원인을
확인했다: 가속 중 실제 pitch 2.75° 일 때 추정 1.60°. 저항 0.05 N/(m/s) 에서는 진폭이
커지고 0.3 에서는 느리게 수렴했다 — 실기 저항을 모르므로 이득만으로는 못 막는다.

- 광류 속도 c 를 차분해 기체 수평 가속도를 만든다: a_x = dc_pitch/dt, a_y = −dc_roll/dt,
  LPF τ 0.2 s, ±3 m/s² clamp. 유효 측정 사이 간격 ≤ 350 ms 일 때만 차분한다.
- 위치 유지가 ACTIVE/COAST 이고 가속도 추정이 350 ms 안에 갱신됐을 때만, 상보필터의
  가속도계 기울기 입력에 bodyAx += a_x/g, bodyAy += a_y/g 를 더한다(전방 가속은 가속도계에
  기수 들림 −a_x/g 로 보인다).
- 결과(SIL): 추정이 실제 기울기를 0.1° 안으로 따라가고, 두 저항 조건 모두 수렴.
