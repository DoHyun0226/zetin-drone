## 최신 실험과 기본 지원 코드의 관계

8월 19일 다섯 사이클은 `feat/low-throttle-yaw-control`(`a052dd9`) 구성으로
비행했다. 이 브랜치는 2026-10-14 `main`에 통합됐다(`1dc8582`). 통합된 펌웨어는
비행한 코드와 주석만 다르므로, 축 우선순위 배분·yaw 권한 상태의 비행 기록은
현재 기본 코드에도 해당한다.
통합 전 실기 게이트는 [벤치 절차](power_on_bench_procedure.md)의 2026-10-14
기록으로 대조했다. 4단계는 다섯 사이클로 통과했고, 1–3단계는 수행자 확인만 있고
수치는 남아 있지 않다.

통합 직전에 지상국 무장 확인을 고쳤다(`98df52e`). 확인 시간이 지난 뒤 도착하거나
판정된 `Armed=1`을 무장 성공으로 받아들이던 결함이다. 이 수정과 무장 거부·확인
시간 초과·failsafe 경로는 아직 비행 기록이 없다. 다섯 사이클을 무조종 위치 유지
성공으로 옮겨 쓰지 않으며, 실제 기체에 마지막으로 업로드된 커밋은 소스 폴더나
로그 파일명만으로 확정할 수 없다.

## 현재 검증과 남은 관문

2026-10-14 기본 코드의 Python 테스트 및 호스트 네이티브/SIL 실행을 포함한
`unittest` **200개가 skip 없이 통과**했다. 이 개수는 바깥 테스트 개수이며 내부 C++
케이스를 다시 합산하지 않는다. 같은 커밋의 `main` CI에서 주력·보류 후보·진단
**9개 스케치가 ESP32 코어 3.3.10으로 컴파일 통과**했다. 2026-09-07 점검의
빌드·검사 기록은 [정합성 점검 기록](reports/2026-09-07-documentation-audit.md)에 있다.

보드 빌드의 비행 성능, 현재 배터리·기구 상태를 이번 문서 점검으로 확정하지 않는다.
